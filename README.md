# Adaptive Agent Core

**زبان / Language:** [فارسی](README.fa.md) · [English](README.en.md)

## معرفی

این مخزن شامل دستورالعملی متنی برای هدایت مدل‌های هوش مصنوعی در نقش تحلیلگر، برنامه‌ریز و اجراکننده است. این یک چارچوب راهنماست، نه برنامه‌ای مستقل؛ قابلیت‌ها و اجرای ابزارها به مدل و محیطی بستگی دارد که از آن استفاده می‌کنید.

## شروع سریع

[دستورالعمل عامل را باز کنید](agent-directive.md) و متن را در تنظیمات دستورهای سفارشی مدل خود قرار دهید. اگر مدل توانایی بازکردن پیوندها را دارد، می‌توانید [پیوند مستقیم متن](https://raw.githubusercontent.com/hazish-dev/adaptive-agent-core/main/agent-directive.md) را برای همان گفت‌وگو بفرستید. در غیر این صورت، متن فایل را کپی کنید.

> فرستادن پیوند تضمین نمی‌کند که مدل بتواند آن را بخواند یا برای گفت‌وگوهای بعدی به خاطر بسپارد. این مخزن اتصال خودکار به مدل‌ها یا اجرای ابزارها را فراهم نمی‌کند.

## Overview

This repository provides a text instruction set for guiding AI models as analysts, strategists, and executors. It is an instruction framework, not a standalone application. Available capabilities and tool execution depend on the model and its host environment.

## Quick start

Open [the agent instructions](agent-directive.md) and add the text to your model's custom instructions. If the model can access web links, share the [direct raw-text link](https://raw.githubusercontent.com/hazish-dev/adaptive-agent-core/main/agent-directive.md) for that conversation. Otherwise, copy and paste the file contents.

> Sharing a link does not guarantee that a model can read it or remember the instructions in future conversations. This repository does not provide automatic model connections or tool execution.
